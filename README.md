# Dota AI Coach

Десктоп-коуч для Dota 2: смотрит на окно игры и в будущем будет разбирать матч и подсказывать голосом.
Пока работает **живой захват** окна Dota 2 (только наблюдение) и разбор записанных кадров и видео.

## Установка и обновления

**Первый раз.** Установите Dota AI Coach (`DotaCoach-Setup-0.1.0.exe`). Затем на странице [Releases](../../releases/latest) скачайте `DotaCoach-<версия>-update.zip`, распакуйте его и запустите `install.bat`. Windows попросит права администратора.

**Дальше всё само.** Коуч проверяет обновления при запуске и раз в 6 часов. Когда выходит новая версия, в левом нижнем углу появляется кнопка «⬆ Обновление». Её же можно установить в «Настройки → Обновления». Коуч скачивает версию, сверяет SHA-256 и перезапускается.

**Откат.** Запустите `rollback.bat` из архива: он вернёт версию, которая стояла до последней установки (`app.asar.prev`).

**Для живого захвата** включите в Доте «Настройки → Видео → Оконный без рамки». Если коуч не видит игру, на вкладке «Живая игра» есть список окон, которые он видит, а журнал лежит в `%APPDATA%\Dota AI Coach\live.log`.

## Как выпустить новую версию

1. Внесите изменения в `app/` и поднимите `version` в `app/package.json` (например, `0.2.0` → `0.3.0`).
2. Напишите, что нового, в `docs/release-notes/v0.3.0.md`. Коуч покажет этот текст в «Настройки → Обновления».
3. Если к релизу нужно приложить дополнительные файлы, положите их в `release-extras/v0.3.0/`.
4. Запушьте коммит и тег:
   ```
   git tag v0.3.0
   git push origin main v0.3.0
   ```
   GitHub Actions (`.github/workflows/release.yml`) сам соберёт `app.asar`, `app.asar.sha256` и `DotaCoach-0.3.0-update.zip` и опубликует релиз. После этого коуч у всех предложит обновиться.

Собрать файлы локально можно так: `python tools/make_release.py` (результат в `dist/`).

## Что где

| Путь | Что это |
|---|---|
| `app/` | Код приложения в том виде, в каком он лежит в `app.asar`: `out/main` — главный процесс, `out/preload`, `out/renderer` — интерфейс, движок и значок поверх игры |
| `app/out/main/live.js` | Поиск окна Доты, разрешение на захват, значок поверх игры, журнал `live.log` |
| `app/out/main/updater.js` | Обновление из GitHub Releases |
| `app/out/renderer/assets/engine-live.js` | Источник кадров «живой захват» и его состояния |
| `app/out/renderer/overlay/` | Значок «Коуч» поверх игры |
| `tools/` | Сборка `app.asar` и релиза (Python 3, без зависимостей) |
| `installer/` | `install.bat` и `rollback.bat` для ручной установки |
| `docs/PORTING.md` | Как перенести изменения в исходники на TypeScript |

## Исходники

`app/` собран из исходников на TypeScript (electron-vite) версии 0.1.0, но код не минифицирован и читается нормально. Когда исходники появятся в репозитории, сборку релизов лучше перевести на них. Как перенести правки, описано в `docs/PORTING.md`.

Доступ к игре только на чтение: снимок окна средствами Windows. Коуч не читает память игры и не вмешивается в процесс `dota2.exe`. Подсказки во время матча пока выключены (этап J в плане).
