# Product

## Platform

web

(Electron 44: окно коуча и окно подсказок поверх игры — страницы Chromium; React 19 в окне коуча, обычный DOM в подсказках.)

## Users

Игроки Dota 2 на Windows — от новичка до опытного (решение 2026-10-18: «для всех»; подробность регулируется в
настройках). Ситуация: идёт матч, игрок смотрит на игру, а не на коуча; на чтение подсказки — доли секунды, в драке —
ноль. Между матчами и после смерти — время разобраться спокойно.

## Product Purpose

Локальный ИИ-коуч: смотрит на окно Доты (свой распознаватель по картинке) и получает данные игры (Valve GSI), из них
строит модель матча и показывает короткие подсказки поверх игры, разбор смерти и матча, подбор героев в драфте.
Успех — игрок за матч получает несколько своевременных подсказок, которые понимает с одного взгляда, и коуч ни разу
не мешает играть.

## Positioning

Работает только на компьютере игрока: без платных API, без чтения памяти игры, без ввода в игру. Каждая подсказка
опирается на распознанные факты и правила; процент показывается только при достаточной уверенности оценки.

## Operating Context

Окно Доты — «полноэкранный в окне» или «окно» (в эксклюзивном полноэкранном рисовать поверх нельзя, интерфейс об этом
предупреждает). Подсказки — прозрачное окно поверх игры: без фокуса, пропускает клики. Окно коуча — настройки, состояние
матча, драфт, база знаний, история; открыто на втором мониторе или между матчами.

## Capabilities and Constraints

- Зоны подсказок: «Важное» (опасность), «Решения» (с процентом), «Тайминги», «Разбор» (после смерти/матча).
- Очередь подсказок: приоритеты, не больше N на зону, TTL, вытеснение важным, тишина в драке для неважного.
- Подробность текста: коротко / обычно / подробно (по умолчанию — коротко, решение 2026-10-18).
- Раскладка — в единицах экрана u = min(высота, ширина × 9/16), запретные области HUD Доты — `src/data/hud-overlay-layout.json`.
- Нельзя выдумывать советы, тайминги, проценты: только данные движка; нет данных — честное «ожидание/неизвестно».
- Новые runtime-зависимости — только после вопроса владельцу.

## Evidence on Hand

Записи и кадры игры владельца (локально, не в репозитории): `.tmp/video-frames`, `tests/fixtures/hud` (с никами).
Демо-подсказки для предпросмотра — `src/shared/hud-samples.ts` (помечены как примеры).

## Product Principles

1. Игра важнее коуча: ни одна подсказка не закрывает HUD Доты и центр боя.
2. Одна мысль — одна подсказка: действие в заголовке, причина — одной-двумя строками.
3. Честность: неизвестное показывается как неизвестное, устаревшее — уходит.
4. Тихо по умолчанию: коуч молчит, пока нечего сказать.

## Accessibility & Inclusion

Срочность не только цветом (значок другой формы + слово «Срочно»); «Уменьшить анимации»; размер подсказок 80–140 %;
контраст текста ≥ 4.5:1 поверх игры.
