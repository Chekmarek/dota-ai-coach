# Аудит коуча (этап 1 ночной задачи, 2026-10-18, версия 0.13.8)

Подробный разбор каждой подсказки (частоты по 5 матчам 18.10, когда бред, решение) — `docs/COACH_AUDIT.md`
(этап 1 прошлой задачи). Здесь — карта системы после 0.13.8, что осталось не так и что даёт STRATZ.

## Карта: что коуч умеет

| Слой | Где | Что |
|---|---|---|
| Данные игры | `src/core/gsi` | Valve GSI своего героя: часы, HP/мана, золото, предметы с перезарядками, способности, выкуп, свои здания, события (Рошан, Аегис) |
| Экран | `src/core/vision`, `src/engine` | мини-карта (кто где, кто пропал), верхняя панель (кто жив), полоски здоровья над героями (HP и уровень врагов рядом) |
| Состояние матча | `src/core/match-state` → `coach/view.ts` → `coach/game-context.ts` | снимок с уверенностью и возрастом каждого поля; стадия, позиция 1–5, герой |
| Память матча | `coach/memory.ts` | история раз в секунду, смерти (что было готово, кто рядом), драка, покупки, Рошан |
| База знаний | `resources/data/kb/<патч>` | герои, предметы, механика (Liquipedia), статистика OpenDota (матчапы, сборки профи, кривые профи), STRATZ рейтинг (кривые и покупки Divine–Immortal по позициям), Турбо (матчапы, справочник механики) |
| Правила (анализаторы) | `coach/rules/*.ts` | драка, опасность, линия, экономика, макро, тайминги, драфт — 40+ подсказок |
| Ошибки и разборы | `coach/mistakes.ts`, `coach/reviews.ts` | ошибки с игровым временем, разбор смерти (причины по важности), разбор матча |
| Очередь (арбитр) | `coach/queue.ts`, `coach/engine.ts` | приоритет, уверенность, TTL, кулдауны, лимит в минуту, тишина в драке, снятие устаревших |
| ИИ | `coach/ai.ts`, локальный llama-server (qwen3) | выбор «что делать и куда» из вариантов правил, объяснения разборов; свободная фраза в матче выключена |
| Вывод | `main/live/hud-window.ts` | окно поверх игры: только в матче и когда Дота активна (0.13.5–0.13.6) |
| Драфт | `core/draft`, страница «Драфт» | подбор героя по матчапам и связкам, угрозы врагов, предметы против них |

## Что осталось не так (после 0.13.8)

1. **Нет единого арбитра.** Решения размазаны: часть в правилах (стадия, роль), часть в очереди (лимиты), часть
   в движке (порядок). На экране одновременно до 7 подсказок (зоны: тревога 1, решение 2, тайминги 3, разбор 1).
   Противоречия решаются точечно (только «Вступать»/«Отходи»): «Пушить» рядом с «3 врага пропали — назад»
   возможно.
2. **Причины без цифр.** «Против Invoker: Black King Bar», «Аванпост врага рядом — захватите», «Бьют башню» — без
   числа, на котором основан совет.
3. **Карта без «достижимо».** Руна объявляется, даже если вы на другом конце карты; Рошан — без оценки, есть ли
   сила его взять.
4. **Шанс драки** не учитывает ману и готовность ключевых предметов врагов (их не видно), свои ключевые предметы —
   слабо.
5. **Выкуп** — только «хватает/не хватает»; угроза базе в правилах не учитывается.
6. **Разбор матча** — без сравнения с сильными игроками и без «что сделал бы сильный игрок».
7. **Нет профиля игрока**: одинаковые ошибки из матча в матч не замечаются.
8. **Драфт-стадия** не готовит данные по всем 10 героям под матч (ключевые предметы врагов — из сборки профи, а не
   рейтинга по позиции).
9. **Обязательные тесты** «другое окно → оверлея нет», «в драке нет фарма», «нет интернета → кэш» — первый есть
   (hudShouldShow), второго и третьего как отдельных проверок нет.

## STRATZ API (проверено запросами 2026-10-18)

- **Доступ:** GraphQL `https://api.stratz.com/graphql`, токен владельца (файл `%USERPROFILE%\.stratz-token.txt`).
- **Лимиты** (заголовки ответа): 8 запросов/с, 150/мин, 1 500/ч, 15 000/сутки.
- **heroStats** — только рейтинговые матчи (фильтра режима нет, Турбо нет):
  - `stats` — по минутам, позиции, рангу: средние добивания, ценность, опыт, уровень, смерти, KDA…;
  - `itemFullPurchase` / `itemStartingPurchase` / `itemBootPurchase` / `itemNeutral` — что и на какой минуте покупают, с долей побед;
  - `heroVsHeroMatchup`, `matchUp` — матчапы и связки по рангу; `laneOutcome` — итоги линии; `talent`, `abilityMin/MaxLevel`;
  - `winDay/Week/…` — доля побед, тут фильтр режима есть (в т. ч. Турбо).
- **match(id)** — разобранные матчи: игроки, позиции, `stats` (поминутно: добивания, золото, опыт, ценность,
  смерти и убийства с координатами, покупки, руны, варды), `playbackData` (позиции всех героев по секундам в клетках
  карты, здоровье, уровни, золото, инвентарь, смерти) — для «режима тени».
- **player(id)** — история игрока: у владельца (аккаунт 265580936) профиль скрыт (`isAnonymous: true`), матчи не
  отдаются. Профиль ошибок строится из локальной истории коуча.
- **Про-матчи:** `league`, `team`, плюс id матчей из OpenDota explorer — STRATZ отдаёт их через ~сутки после игры.
