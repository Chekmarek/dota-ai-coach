# Фильтр внимания (attention gate)

Слой между генераторами подсказок и выводом (окно поверх игры, звук, голос). Генераторы — правила
(`src/core/coach/rules`), ошибки, совет ИИ — не менялись: движок отдаёт все их подсказки за тик
(`CoachUpdate.offered`), фильтр решает, **что, когда и как коротко** показать. Код: `src/core/gate` (чистое ядро,
о захвате экрана не знает — только сигналы), сигналы из снимка коуча — `src/core/coach/gate-signals.ts`,
подключение — `src/main/coach/service.ts`. Выключается в «Живая игра» → «Фильтр внимания» (`settings.gate.enabled`):
тогда подсказки идут как раньше.

## Контракт подсказки

| Поле | Что это |
|---|---|
| `type` | ruleId генератора: по нему кулдауны, «не нужно», метрики |
| `priority` | `critical` (срочно) / `useful` (= прежний `advice`) / `info` |
| `confidence` | 0…1, как у генератора |
| `short` | ≤ 3 слов, повелительно: «Отходи», «Купи Black King Bar» (название — одно слово) |
| `voice` | ≤ 5 слов или `null` — только у срочных (фразы для заранее записанных клипов) |
| `reason` | один факт с числом из самой подсказки: «шанс 34%», «Риск смерти 71%»; нет числа — `null` |
| `details` | полный текст генератора — только в спокойный момент (мёртв, на базе, пауза, до горна) и в «Подробно» |
| `expiresAt` | когда устаревает |

Генератор может задать `short` / `voice` / `reason` сам (`HintDraft.gate`), иначе они выводятся детерминированно
(`src/core/gate/derive.ts`): короткая фраза — по таблице типов, причина — из текста подсказки (первая часть с числом)
или из её фактов матча (справочные цены и «обычно к минуте» — не причина). Ничего не придумывается.

## Когда показывать

**Драка** (`moment.ts`) — данные игры и зрение вместе: оглушён/заглушён; здоровье −8 п.п. за 3 с; враг вплотную и
урон или нажатая способность; драка по зрению с 2+ врагами. Держится 5 с после последнего признака.
**Спокойно**: мёртв, пауза, до горна, на своей базе, идёт к базе, или 6 с без признаков драки и без врагов вплотную.
Враг на линии рядом без урона — не драка, но и не «тихо»: несрочное ждёт.

- В драке проходят только срочные, несрочная карточка с экрана уходит.
- Несрочная — не больше одной за `budgetSec` (по умолчанию 50 с), тот же тип — не чаще 3 мин, та же фраза — не чаще 3 мин.
- Срочная — мимо бюджета, свой кулдаун на тип 10 с («Бьют здание» — 60 с).
- Несрочное ждёт спокойного момента не дольше 90 с; ситуация прошла (генератор перестал подтверждать) — уходит.
- Уже сделано: предмет уже есть, герой уже у руны — не показываем.
- Уверенность ниже `minConfidence` (0,6) — не в игре, а одной строкой в разборе матча.
- Разборы смерти и матча идут мимо фильтра (момент спокойный по определению); разбор смерти сжат: причина, совет,
  выкуп — если есть что делать; текст ИИ — только предложения-советы, не повторяющие шаблон.

## «Не нужно» и метрики

Клавиша «не нужно» (по умолчанию `Ctrl+Alt+N`): тип последней показанной подсказки молчит до конца матча. Нажимали в
3 разных матчах — тип понижается до `info` (без голоса и мимо срочных). Хранится в `<папка данных>/coach-gate.json`
вместе с метриками по типам: показана / выполнена / проигнорирована / «не нужно» / не проверить. «Выполнена» —
эвристика: предмет появился за 90 с; «Отходи» — за 10 с стал на 700 ед. ближе к базе (умер — нет); руна — подошёл за
30 с; совет экономики, линии, макро — генератор перестал его подтверждать за 30 с. В сеть ничего не уходит.

Панель отладки — «Живая игра» → «Фильтр внимания» → «Отладка фильтра»: сколько пришло, показано, скрыто и почему.

## Замер (записи GSI 22.10 и 24.10, без зрения — только данные игры)

| | 22.10 до | 22.10 после | 24.10 до | 24.10 после |
|---|---|---|---|---|
| Подсказок в минуту | 2,56 | 1,00 | 2,12 | 0,89 |
| Несрочных в минуту | 2,52 | 0,88 | 2,03 | 0,74 |
| Несрочных в драке (жив, после начала урона) | 18 | 3 | 57 | 3 |
| Символов на карточке | 92 | 44 | 98 | 49 |
| Слов в заголовке | 5,5 | 2,2 | 5,5 | 2,2 |

Драка в замере — по данным игры: здоровье −12% за 3 с или смерть. С живым зрением генераторов больше (в настоящих
матчах было ~5,7 подсказки в минуту), фильтр режет их тем же бюджетом.
