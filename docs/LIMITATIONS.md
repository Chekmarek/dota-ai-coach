# Известные ограничения

Обновляется после каждого этапа. Последнее обновление: версия 0.3.0 (этап C — числа HUD, имя героя, база знаний), 2026-10-11.

## Что реально работает (проверено тестами)

- Оболочка: 8 экранов, настройки, воспроизведение папки кадров и видео, установщик и портативный zip.
- **Распознавание чисел HUD** (стандартный HUD, 16:9): игровое время, счёт обеих команд, золото, здоровье и мана
  (текущее/максимум, в т.ч. красные цифры при смерти героя), уровень.
  - Собственный OCR по шаблонам символов; шаблоны собраны из 9 кадров записи пользователя.
  - Проверка на 6 кадрах, не участвовавших в обучении (вторая запись + скриншот Shadow Fiend с открытым магазином,
    0:43, золото 99999): 38 из 42 значений верно, **0 неверных**, 4 — честно отклонены как неуверенные.
  - С записью 3 (Monkey King, вражеский Morphling): 89 из 98 верно, **0 неверных**, 9 отклонены.
  - Защита: если цифра обрезана краем области, значение отбрасывается целиком (раньше «14» читалось как «1»).
  - Скорость: ~10 мс на кадр в приложении (≈ 1 % процессора при 4 кадрах/с).
- **Имя героя над портретом**: буквы сравниваются с образцами, ответ выбирается только из 127 известных имён
  (учитываются число слов, длина слов и форма букв). 16 из 23 размеченных кадров узнаны, **0 неверных**.
  Monkey King и Morphling узнаются, даже если исключить их буквы из образцов. Известно, каких букв ещё нет в образцах:
  A, B, C, D, F, J, Q, S, T, U, V, W, X — имена с ними узнаются хуже (по форме и остальным буквам).
  Не читается на очень пёстром или светлом фоне (Shadow Fiend на песке) — тогда «не распознан».
  Имя может мигать между кадрами — сглаживание во времени будет в модели состояния матча (этап D).
- **База знаний** патча 7.41f: 127 героев (характеристики, 734 способности с перезарядкой/маной и описаниями на русском,
  таланты), 409 предметов (цена, рецепты, атрибуты). Самопроверка цен находит 3 расхождения.

## Ограничения распознавания

- **Нижняя панель HUD показывает выбранного юнита**, а не обязательно героя игрока. Если выбран враг (красная полоса HP),
  программа помечает это («Нижняя панель показывает: вражеского юнита»); золото в этом случае отображается как 0.
  Если выбран союзник — отличить его от своего героя пока нельзя (нужно распознавание имени/портрета героя).
- Положение уровня зависит от ширины панели (у героев разное число способностей) — определяется по краю полосы маны.
  У мёртвого героя опора иногда ненадёжна — тогда уровень не читается.

- **Мало обучающих данных:** две 30-секундные записи одного героя (Kez) на 44-й минуте. Цифры шрифта HUD везде одинаковые,
  поэтому для других героев числа должны читаться так же, но это **не проверено**. Нужны записи начала игры,
  с открытым магазином, других героев, других разрешений.
- Поддерживается только соотношение 16:9 (1920×1080 проверено; 2560×1440, 1280×720 — только расчёт координат).
  Для 21:9, 16:10, 4:3 распознавание честно отключается («интерфейс не поддерживается»).
- Изменённый масштаб HUD в настройках Dota, нестандартные HUD-скины — не поддерживаются.
- Если в настройках уменьшить «максимальную ширину кадра» ниже 1920, точность может упасть (шаблоны сняты с 1080p).
- Видео проигрывается в реальном времени (1×).

## Ограничения базы знаний

- Данные **не сверены вручную** с патч-ноутами (`imported-unverified`). Точные расчёты не должны их использовать до проверки.
- Названия героев, предметов и способностей — английские (как и в русском клиенте); описания способностей — на русском.
- Описания содержат подстановки вида `%katana_distance%` — значения ещё не подставляются.
- Источники и даты — в [DATA_SOURCES.md](DATA_SOURCES.md). Обновление после патча: `npm run kb:import`.
