# Политика использования и источники информации

Статус: **черновик**. Проверка правил Valve (этап J) выполнена 2026-10-16 — см. раздел в конце: прямого разрешения или запрета нет.

## Режимы

| Режим | Статус | Где задаётся |
|---|---|---|
| Разбор записей (replay) | **разрешён** | `src/main/policy/policy-gate.ts` |
| Живой захват без подсказок (live-observe) | **разрешён** с 0.5.0 — решение владельца 2026-10-12 | там же |
| Подсказки в обычных матчах | **включены по умолчанию** — решение владельца 2026-10-13 | «Настройки → Live-подсказки» и карточка на «Живой игре» (`settings.hints.enabled`) |
| Подсказки в рейтинговых матчах | отдельный переключатель, по умолчанию включён; **решает пользователь** (решение владельца 2026-10-13) | там же (`settings.hints.ranked`) |

## Решение владельца 2026-10-16: подсказки поверх игры и ИИ во время матча

- **Вывод:** подсказки показываются в прозрачном окне поверх окна Dota «как часть игры» (не перекрывая HUD игры);
  окно пропускает клики, не берёт фокус и исключено из захвата экрана. Это меняет пункт «Вывод» решения 2026-10-13.
- **ИИ во время матча:** локальная модель подсказывает «что делать и куда идти» весь матч, но **по событию**, а не по
  таймеру: возрождение, конец драки, 6-й уровень, ключевой предмет, Рошан/аегис, атака на башню, резкая смена карты,
  простой, смена плана. Выбирает только из вариантов, посчитанных правилами коуча, и только по его фактам; ответ
  проверяется, иначе показывается шаблон. Экономия: та же обстановка не спрашивается повторно (кэш ответов), не больше
  4 советов и пересказов в минуту, ошибки объясняются только в разборах, во время матча llama-server берёт четверть
  ядер вместо половины (решение владельца 2026-10-16: «когда нужны, и чтобы много не потребляло»).
- **Положение окна Доты** коуч узнаёт у Windows (user32 `GetClientRect`/`ClientToScreen` по номеру окна из захвата):
  один процесс PowerShell раз в секунду печатает прямоугольник окна, пока видна игра. Это не чтение памяти игры и не
  вмешательство в процесс — так любое приложение узнаёт, где чужое окно. Не вышло — подсказки занимают экран.
- **Данные:** разрешено брать открытую статистику, но только текущего патча (`stats.json`, docs/DATA_SOURCES.md).
- **Экраны:** подсказки должны работать на любом размере и пропорциях экрана (этап 3).
- **Рейтинг:** Dota в GSI не сообщает, рейтинговый матч или обычный, поэтому переключатель «Подсказки и в рейтинговых
  матчах» не может срабатывать сам — интерфейс прямо говорит об этом: перед рейтингом подсказки выключает пользователь.
- **История советов** (этап 4): `<папка данных>/history/` — по файлу на матч (подсказки, ошибки, разборы), последние
  50 матчей, только на этом ПК. Ников, steamid и ключей там нет.

## Решение владельца 2026-10-13: live-подсказки

Владелец разрешил разработку live-подсказок при соблюдении условий:

- **Источник данных:** только Valve Game State Integration (GSI) — официальный механизм Valve, только чтение, данные о собственном герое игрока — и уже существующее зрение окна. Чтение памяти, DLL, эмуляция ввода и любые действия в игре запрещены.
- **Вывод:** отдельное окно коуча. Не поверх окна Dota, не перехватывает клавиатуру и мышь.
- **Прозрачность:** коуч не скрывает свою работу от игры, системы или Valve. Обход защиты игры запрещён.
- **Включение:** переключатель в настройках. Подсказки в обычных матчах включены по умолчанию; в рейтинге переключатель тоже включён по умолчанию (решение владельца). Рядом с переключателем предупреждение о риске для аккаунта по правилам Valve.
- **Риск:** правила Valve о сторонних программах, дающих подсказки в матче, не проверены. Нарушение может привести к блокировке аккаунта. Правила Valve не проверены: в поиске подтверждения ни «разрешено», ни «запрещено» не найдено. Проверка правил (этап J) остаётся открытой задачей, а не условием включения.

Переключатели подсказок есть в интерфейсе (с 2026-10-13): «Настройки → Live-подсказки» и карточка на странице «Живая игра». Рядом — предупреждение о риске для аккаунта. Сами подсказки появятся на следующих этапах; переключатели заранее сохраняют выбор пользователя.

## Данные из игры — Valve Game State Integration (GSI)

GSI — официальный механизм Valve: Dota сама отправляет HTTP-запросы с данными о матче на адрес из файла
конфигурации. Коуч только принимает их.

- **Приёмник** — только `127.0.0.1` (из сети не виден), порт из настроек (по умолчанию 53790). Если порт занят,
  коуч показывает «порт занят» и сам другой порт не выбирает. Принимается только `POST` с телом до 256 КБ
  и верным секретом `auth.token` (32 случайных байта, создаются один раз и хранятся в `settings.json`;
  сравнение за постоянное время). Запросы с заголовком `Origin` (со страниц браузера) отклоняются.
  Отклонённый запрос — одна строка в `live.log` с причиной, без содержимого.
- **Что пишется на диск, в папку Dota**: по кнопке «Подключить» (после подтверждения с полным путём) —
  **один файл** `steamapps/common/dota 2 beta/game/dota/cfg/gamestate_integration/gamestate_integration_dotacoach.cfg`.
  В нём адрес приёмника, частоты отправки (`timeout 5.0`, `buffer 0.1`, `throttle 0.1`, `heartbeat 30.0`),
  секрет и блоки данных `provider, map, player, hero, abilities, items`. «Отключить» удаляет только этот файл.
  Папку игры коуч находит по реестру (`HKCU\Software\Valve\Steam`, `SteamPath`) и `steamapps/libraryfolders.vdf`
  или берёт указанную пользователем.
- **Файлы Steam коуч не меняет.** Параметр запуска `-gamestateintegration` пользователь добавляет сам:
  Steam → Dota 2 → Свойства → Параметры запуска (в интерфейсе — инструкция и кнопка «Копировать»).
- **Что пишется на диск, в папку данных коуча**: записи сессий `gsi-sessions/<дата>.jsonl` (выключаются
  в настройках). Из них вырезаются ники, steamid/accountid и блоки `provider` и `auth`; хранятся последние 20 файлов.
- С 0.12.0 дополнительно запрашиваются `buildings` (здания **своей** команды — «бьют вашу башню») и `events`
  (события матча: Рошан убит, аегис подобран и т. п.) — решение владельца 2026-10-16. Файл cfg переписывается сам
  при запуске коуча, если он уже установлен (`refreshCfg`); Dota подхватит его после перезапуска игры.
- Блоки `allplayers`, `draft`, `minimap` не запрашиваются: в режиме игрока Dota не присылает
  данных о противниках, это решение Valve, а не ограничение коуча.

## ИИ-помощник (0.11.0) — что может уйти в облако

Решение владельца: только бесплатные варианты; по умолчанию ИИ **выключен**; основной вариант — небольшая
**локальная** модель на процессоре; облако — по желанию пользователя с его собственным ключом.

- **ИИ ничего не считает и не смотрит игру сам.** Он получает вопрос и короткий список фактов, которые уже посчитал
  коуч (текущий матч, база знаний, разбор записи, факты после матча), и пересказывает их. Числа в ответе сверяются
  с этими фактами; несовпадение помечается «⚠ не проверено».
- **Локальная модель** (Qwen3 1.7B или 4B, лицензия Apache-2.0) и сборка llama.cpp скачиваются только по кнопке
  «Скачать локальный ИИ» в `<папка данных>/ai/` с GitHub (ggml-org/llama.cpp) и Hugging Face. Версии и SHA-256
  закреплены в `src/main/ai/local/manifest.ts` и проверяются после скачивания; «Удалить» стирает папку `ai/` целиком.
  `llama-server` слушает только `127.0.0.1` на случайном порту, запускается при первом вопросе с пониженным
  приоритетом и останавливается после 5 минут простоя и при выходе. Данные с ПК не уходят.
- **Облако** (любой OpenAI-совместимый сервер): вызывается **только** когда выбран вариант «Облако» **и** включено
  согласие «Согласен отправлять в облако…» (`ai.sendToCloudConsent`, по умолчанию выключено; без него main-процесс
  отказывает до отправки). Отправляется: вопрос, факты коуча (игровые значения, названия героев и предметов, время),
  до двух прошлых реплик чата. **Не отправляется:** ники, steamid/accountid (их нет и в фактах), ключ GSI, пути к файлам,
  кадры и видео. Адрес — только `https://` (или `http://` для сервера на этом же ПК).
- **Ключ облака** хранится только в main-процессе, зашифрованным Windows (Electron `safeStorage`, DPAPI) в
  `<папка данных>/ai/keys.json`; в `settings.json`, в интерфейс и в журнал он не попадает (проверяется тестами).
  Без шифрования Windows ключ не сохраняется.
- **GigaChat** пока недоступен: его API требует корневого сертификата Минцифры, который коуч не встраивает и не
  устанавливает в систему.
- «Полезно» / «Мимо» под ответами пишутся только в `<папка данных>/ai/feedback.jsonl` и никуда не отправляются.
- Журнал (`live.log`) получает только коды ошибок ИИ и состояние llama-server — без вопросов, ответов и ключей.
- Подсказки ИИ во время матча пока не включены (следующий этап); заготовка `phraseCard` к уведомлениям не подключена.

## Что приложение получает и откуда

- **Изображение:**
  - записи — только файлы, явно выбранные пользователем (папка кадров или видео); доступ через схему `dcmedia://`, которая отдаёт лишь зарегистрированные файлы;
  - живой режим — снимок **окна** Dota 2 стандартным захватом Windows (`desktopCapturer`), только чтение. Разрешение на захват получает только скрытое окно движка и только на видео.
- **Игра:** нет чтения памяти, DLL, вмешательства в процесс `dota2.exe`, сетевых запросов к Steam/Valve. Единственный канал от игры — GSI (см. раздел выше): коуч получает данные, которые Dota отправляет о герое игрока, и пишет только свой файл конфигурации в папку GSI Dota.
- **Ввод в игру:** отсутствует. Unit-тест «сторож зависимостей» проверяет, что в проекте нет библиотек эмуляции клавиатуры/мыши и доступа к памяти процессов.
- **Значок поверх игры:** прозрачное окно без фокуса, пропускает клики, исключено из захвата экрана (`setContentProtection`).
- **Интернет:** скачивание локального ИИ по кнопке и облачный ИИ с согласием (раздел выше); проверка новых версий в GitHub Releases репозитория `Chekmarek/dota-ai-coach` (при запуске и раз в 6 ч). Установка — только по кнопке «Установить»: коуч скачивает `app.asar` из релиза, сверяет SHA-256 и подменяет свой файл после выхода (в Program Files — с запросом прав администратора Windows), затем перезапускается. Игру и её файлы обновление не трогает. Сумма лежит в том же релизе, поэтому защищает от повреждённой загрузки, но не от подмены релиза.
- **Журнал:** `<папка данных>/live.log` — найденные окна, решения по разрешениям, состояния живого режима, проверки обновлений.

## Проверка правил Valve (этап J) — 2026-10-16

Проверены открытые источники: правила поведения Steam, заявления Valve по Dota 2, новости о банах, документация
GSI и FAQ существующих GSI-коучей. **Итог: прямого разрешения или прямого запрета программ, дающих советы во время
матча по GSI и видимому экрану, Valve не публиковала.** Решение владельца (подсказки включены, в рейтинге — тоже)
не меняется; ниже — что известно и чего держаться, чтобы риск оставался минимальным.

**Что Valve запрещает и за что банила:**
- *Чтение данных клиента Dota во время игры.* Февраль 2023, пост «Cheaters will never be welcome in Dota»: более
  40 000 вечных банов; Valve: если программа читает данные из клиента Dota во время игры, аккаунт может быть
  заблокирован навсегда, включая профессиональных игроков. Ловушка-«приманка» в памяти клиента — значит, речь о
  чтении памяти/скрытых данных. Источники: [esports.gg](https://esports.gg/news/dota-2/dota-2-bans-40000-cheaters-in-huge-ban-wave/),
  [Kotaku](https://kotaku.com/valve-steam-dota-2-cheating-honeypot-ban-client-patch-1850149606).
- *Скрытая информация.* Патч, закрывший профили игроков на стадии выбора и команду `record` в матчмейкинге
  (запись демо с невидимой клиенту информацией), — против помощников драфта (Overwolf). Позже — вечные баны
  пользователей Overplus: сбор чужих пиков в обход скрытых профилей. Источники:
  [esports.gg](https://esports.gg/news/dota-2/dota-2-update-kills-third-party-applications-including-overwolf/),
  [game-tournaments.com](https://game-tournaments.com/en/dota-2/news/44348-player-profiles-in-dota-2-now-cannot-be-seen-before-draft-ends-after-patch-to-make-overwolf-app-stop-working),
  [hawk.live](https://hawk.live/posts/what-is-overplus-dota-2).
- *Правила поведения Steam* запрещают «cheat programs», не определяя их: можно ли считать читом программу, которая
  только советует, — прямо не сказано ([Steam Online Conduct](https://store.steampowered.com/online_conduct/?l=english)).

**Что говорит в пользу допустимости:**
- GSI — официальный механизм Valve (параметр `-gamestateintegration`, по умолчанию выключен с 2022): Dota сама
  отправляет данные, без чтения памяти. В режиме игрока Valve отдаёт **только данные своего героя** — механизм
  специально не раскрывает скрытое.
- Открыто работают коучи с подсказками во время матча на GSI: Dota Coach (Overwolf) пишет «приложение НЕ приведёт
  к бану» и запрещает себя только в официальных турнирных (ticketed) матчах
  ([FAQ Dota Coach](https://dotacoach.gg/en/app/faqs)); LaneMind и другие — живой оверлей по GSI
  ([LaneMind](https://www.lanemind.com/dota-2-ai-coach)). Массовых банов за GSI-коучей в источниках не найдено.
  Это наблюдение, не разрешение Valve.

**Правила для коуча (держать всегда):**
1. Никаких скрытых данных: только GSI и то, что видно на экране игроку. Не читать память, файлы демо матча во время
   игры, профили/историю соперников на стадии выбора.
2. Не встраиваться в процесс Dota (никаких DLL, хуков, оверлея внутри игры): подсказки — отдельное окно поверх.
3. Не играть за игрока: никакого ввода в игру, никаких действий от его имени.
4. Не использовать в официальных турнирных (ticketed) матчах — в интерфейсе стоит предупредить об этом.
5. Предупреждение о риске для аккаунта рядом с переключателями подсказок остаётся: окончательного ответа от Valve нет.

**Остаётся открытым:** официальной позиции Valve нет; при появлении заявления/патча против советчиков в матче
решение пересматривается. Иконки героев и предметов в установщик не кладутся — только сжатые шаблоны
(`src/data/item-templates.json`); портреты из файлов игры читаются на ПК пользователя (решение владельца).
