# Политика использования и источники информации

Статус: **черновик**. Полная проверка — этап J.

## Режимы

| Режим | Статус | Где задаётся |
|---|---|---|
| Разбор записей (replay) | **разрешён** | `src/main/policy/policy-gate.ts` |
| Живой захват без подсказок (live-observe) | **разрешён** с 0.5.0 — решение владельца 2026-10-12 | там же |
| Подсказки в обычных матчах | выключен | там же |
| Подсказки в рейтинговых матчах | выключен | там же |

Переключателей подсказок во время матча в интерфейсе нет намеренно. Включение возможно только изменением кода после записанного здесь решения.

## Что приложение получает и откуда

- **Изображение:**
  - записи — только файлы, явно выбранные пользователем (папка кадров или видео); доступ через схему `dcmedia://`, которая отдаёт лишь зарегистрированные файлы;
  - живой режим — снимок **окна** Dota 2 стандартным захватом Windows (`desktopCapturer`), только чтение. Разрешение на захват получает только скрытое окно движка и только на видео.
- **Игра:** нет чтения памяти, DLL, Game State Integration, вмешательства в процесс `dota2.exe`, сетевых запросов к Steam/Valve.
- **Ввод в игру:** отсутствует. Unit-тест «сторож зависимостей» проверяет, что в проекте нет библиотек эмуляции клавиатуры/мыши и доступа к памяти процессов.
- **Значок поверх игры:** прозрачное окно без фокуса, пропускает клики, исключено из захвата экрана (`setContentProtection`).
- **Интернет:** проверка новых версий в GitHub Releases репозитория `Chekmarek/dota-ai-coach` (при запуске и раз в 6 ч). Установка — только по кнопке «Установить»: коуч скачивает `app.asar` из релиза, сверяет SHA-256 и подменяет свой файл после выхода (в Program Files — с запросом прав администратора Windows), затем перезапускается. Игру и её файлы обновление не трогает. Сумма лежит в том же релизе, поэтому защищает от повреждённой загрузки, но не от подмены релиза.
- **Журнал:** `<папка данных>/live.log` — найденные окна, решения по разрешениям, состояния живого режима, проверки обновлений.
