# Политика использования и источники информации

Статус: **черновик**. Полная проверка — этап J.

## Режимы

| Режим | Статус | Где задаётся |
|---|---|---|
| Разбор записей (replay) | **разрешён** | `src/main/policy/policy-gate.ts` |
| Живой захват без подсказок (live-observe) | **разрешён** с 0.5.0 — решение владельца 2026-10-12 | там же |
| Подсказки в обычных матчах | **включены по умолчанию** — решение владельца 2026-10-13; выключатель в настройках | переключатель в настройках (после реализации) |
| Подсказки в рейтинговых матчах | переключатель в настройках; по умолчанию включён (решение владельца 2026-10-13) | там же |

## Решение владельца 2026-10-13: live-подсказки

Владелец разрешил разработку live-подсказок при соблюдении условий:

- **Источник данных:** только Valve Game State Integration (GSI) — официальный механизм Valve, только чтение, данные о собственном герое игрока — и уже существующее зрение окна. Чтение памяти, DLL, эмуляция ввода и любые действия в игре запрещены.
- **Вывод:** отдельное окно коуча. Не поверх окна Dota, не перехватывает клавиатуру и мышь.
- **Прозрачность:** коуч не скрывает свою работу от игры, системы или Valve. Обход защиты игры запрещён.
- **Включение:** переключатель в настройках. Подсказки в обычных матчах включены по умолчанию; в рейтинге переключатель тоже включён по умолчанию (решение владельца). Рядом с переключателем предупреждение о риске для аккаунта по правилам Valve.
- **Риск:** правила Valve о сторонних программах, дающих подсказки в матче, не проверены. Нарушение может привести к блокировке аккаунта. Правила Valve не проверены: в поиске подтверждения ни «разрешено», ни «запрещено» не найдено. Проверка правил (этап J) остаётся открытой задачей, а не условием включения.

Переключателей подсказок во время матча в интерфейсе нет намеренно. Включение возможно только изменением кода после записанного здесь решения.

## Что приложение получает и откуда

- **Изображение:**
  - записи — только файлы, явно выбранные пользователем (папка кадров или видео); доступ через схему `dcmedia://`, которая отдаёт лишь зарегистрированные файлы;
  - живой режим — снимок **окна** Dota 2 стандартным захватом Windows (`desktopCapturer`), только чтение. Разрешение на захват получает только скрытое окно движка и только на видео.
- **Игра:** нет чтения памяти, DLL, вмешательства в процесс `dota2.exe`, сетевых запросов к Steam/Valve. Единственный канал от игры — GSI (см. решение 2026-10-13): коуч получает данные, которые Valve отправляет игроку о его герое, и пишет только свой файл конфигурации в папку GSI Dota.
- **Ввод в игру:** отсутствует. Unit-тест «сторож зависимостей» проверяет, что в проекте нет библиотек эмуляции клавиатуры/мыши и доступа к памяти процессов.
- **Значок поверх игры:** прозрачное окно без фокуса, пропускает клики, исключено из захвата экрана (`setContentProtection`).
- **Интернет:** проверка новых версий в GitHub Releases репозитория `Chekmarek/dota-ai-coach` (при запуске и раз в 6 ч). Установка — только по кнопке «Установить»: коуч скачивает `app.asar` из релиза, сверяет SHA-256 и подменяет свой файл после выхода (в Program Files — с запросом прав администратора Windows), затем перезапускается. Игру и её файлы обновление не трогает. Сумма лежит в том же релизе, поэтому защищает от повреждённой загрузки, но не от подмены релиза.
- **Журнал:** `<папка данных>/live.log` — найденные окна, решения по разрешениям, состояния живого режима, проверки обновлений.

## Открытые вопросы к этапу J

- Актуальные правила Valve/Steam о сторонних программах, дающих подсказки во время матча (известно, что Valve ранее блокировала такие оверлеи).
- Можно ли распространять иконки героев/предметов для сопоставления шаблонов.
