Заполняйте «итог» по каждому пункту: ✅ / ❌ + что видно. Лог — `%APPDATA%\Dota AI Coach\live.log`.

## 0. Подготовка
- Steam → Dota 2 → Свойства → Параметры запуска: есть `-gamestateintegration`.
- Коуч: «Живая игра» → «Данные из игры (GSI)» → «Подключить». Дота — «Полноэкранный в окне».
- «Настройки → Live-подсказки → Режим игры» = «Определять по данным игры».
