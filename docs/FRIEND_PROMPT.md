# Промпт для Claude Code: переход на исходники (ветка `sources`)

> Для Chekmarek. Скопируй всё, что ниже линии, в Claude Code в папке своего клона `dota-ai-coach`.

---

Мы с другом вместе делаем Dota AI Coach. Раньше я правил собранный код в `app/` и отправлял ему пакеты
«update-for-friend», а он переносил их в исходники. Теперь исходники на TypeScript лежат в ветке **`sources`**
этого репозитория, и **все мои изменения до 0.7.0 туда уже перенесены** (подробности — `MERGE_REPORT.md`,
раздел «Перенос 0.6.0 и 0.7.0»). Дальше работаем только в `sources`. Пакеты `update-for-friend` больше не нужны.

## Что сделать сейчас
1. Переключиться на ветку: `git fetch origin` и `git switch sources`. В `main` и `app/` больше ничего не править.
2. Подготовить проект (Windows, PowerShell). Команды и пояснения — в `README.md`:
   - в `.npmrc` строка `cache=D:\DotaCoach\.cache\npm` — путь с компьютера друга; если у меня другой диск
     или папка, поправь путь локально и **не коммить** эту правку;
   - `npm install` (npm 11 блокирует install-скрипты — разрешённые перечислены в `allowScripts` в `package.json`);
   - один раз скачать Electron: `node node_modules\electron\install.js`
     (кэш можно задать через `$env:ELECTRON_CACHE`).
3. Проверить, что всё работает: `npm run typecheck`, `npm test`, `npm run test:e2e`.
   Часть тестов распознавания пропустится: кадры `tests/fixtures/hud` с никами игроков в репозиторий не кладём,
   это нормально.
4. Запустить коуча: `npm run dev`. Собрать установщик и zip: `npm run dist` → `release\<версия>\`.
5. Прочитать `docs/ARCHITECTURE.md`, `docs/POLICY.md` и `MERGE_REPORT.md`, затем коротко рассказать мне
   по-русски, как устроен проект и где что лежит.

## ВАЖНО: релизы
- **Не выпускать релизы из `app/`.** В `app/` нет распознавания HUD (числа, «чья панель», имя героя) и базы
  знаний. Автообновление поставит такой релиз всем, и у коуча пропадёт зрение.
- Push в `main` и теги `v*` запускают GitHub Actions, которые сразу публикуют релиз. Пока выпуск не переведён
  на исходники, в `main` не пушить и теги не ставить.
- Следующий шаг (обсудим вдвоём, ничего не делать без моего «да»): перевести `auto-release.yml` на сборку из
  исходников (`npm ci`, `npm run dist` на `windows-latest`; `app.asar` брать из
  `release\<версия>\win-unpacked\resources\app.asar`, рядом класть `app.asar.sha256`). Учесть, что база знаний
  лежит не в `app.asar`, а в `resources\data` рядом с ним: старые установки 0.1–0.5 получат её только через
  новый установщик.

## Правила (как и раньше)
- Доступ к игре только на чтение: захват окна и чтение файлов настроек. Никакой памяти, DLL, GSI-хаков,
  ввода в игру. Подсказки во время матча (`live-coach-*`) остаются выключенными.
- Новые зависимости и ослабление CSP — только после обсуждения.
- Новый IPC: проверка отправителя в main, `contextBridge` в preload, проверка данных через zod.
- Новые ключи настроек — со значениями по умолчанию, старый `settings.json` должен загружаться.
- Перед коммитом: `npm run typecheck`, `npm test`, `npm run test:e2e`. Коммиты — в ветку `sources`.
- Кадры с никами игроков, записи матчей и файлы установленной программы в репозиторий не класть.
