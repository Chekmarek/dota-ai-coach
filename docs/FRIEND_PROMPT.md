# Промпт для Claude Code: влить свежие исходники (`sources`) в свою версию, не потеряв свои правки

> Для друга (VOROBEISHESTVO). Шаблон: `python tools/make_friend_kit.py` подставляет версию и кладёт его в пакет
> для друга как `CLAUDE_PROMPT.md`. Скопируй всё, что ниже линии, в Claude Code в папке своего клона `dota-ai-coach`.
>
> **Если нужно просто обновить установленного коуча** — этот промпт не нужен: «Обновления» → «Установить» в самом коуче.
> Промпт нужен, только если у тебя есть свои правки в исходниках и ты хочешь работать дальше с ними и с нашими изменениями.

---

Мы с другом вместе делаем Dota AI Coach (Electron 44 + electron-vite + React 19 + zod 4, vitest, Playwright e2e).
Общие исходники — ветка **`sources`** репозитория `Chekmarek/dota-ai-coach`, сейчас там **{VERSION}**. У меня есть
**мои собственные правки**. Нужно влить в них свежий `sources` так, чтобы **ни одна моя правка не потерялась**.

Что нового в `sources` с 0.17.0 (обновление подачи подсказок — сами советы не переписывались):
- **Фильтр внимания** `src/core/gate` (+ `src/core/coach/gate-signals.ts`): все подсказки идут через него — бюджет
  внимания, тишина в драке, порог уверенности, 1–3 слова на экране, «Заглушить» `Ctrl+Alt+N`. Файл `coach-gate.json`.
- **Фокус матча** `src/core/focus`, `src/main/coach/focus.ts`: одна измеримая цель на матч, смена `Ctrl+Alt+F`,
  итог после матча, звук `focus`.
- **Прогресс** `src/core/progress`, `src/main/coach/progress-store.ts`, страница `src/renderer/pages/Progress.tsx`:
  опыт только за улучшение, звания, серия, достижения, честная статистика. Файл `progress.json`.
- Настройки: новые разделы `gate` и `focus` (значения по умолчанию, старый файл читается без потерь).
- Чаще всего пересекаются с чужими правками: `src/main/coach/service.ts`, `src/core/coach/hud.ts`,
  `src/core/coach/engine.ts`, `src/shared/schemas/settings.ts`, `src/hud/components/cards.ts`, `src/hud/hud.css`,
  `src/renderer/pages/LiveGame.tsx`, `src/renderer/App.tsx`, `src/shared/ipc.ts`, `src/preload/ui.ts`,
  список API в `tests/e2e/app.spec.ts`.
- Захват экрана и зрение (`src/engine`) не менялись и от новой подачи не зависят: без зрения фильтр работает по GSI.

## 1. Найди мои правки (ничего не меняя)
- `git status`, `git stash list`, `git branch -a`, `git log --oneline origin/sources..HEAD` (сначала `git fetch origin`).
- Если моих правок нет в git-клоне (например, я правил только установленную программу) — остановись и спроси меня.
- Коротко перечисли по-русски, что нашёл: файлы и суть каждой правки.

## 2. Сохрани их, прежде чем сливать
- Все незакоммиченные изменения и stash — закоммить в ветку `my-edits` (создай её от текущего состояния).
- Поставь тег `before-merge-<ГГГГ-ММ-ДД>` на эту точку: к ней всегда можно вернуться (`git reset --hard <тег>`).

## 3. Слей `origin/sources` в `my-edits`
- `git merge origin/sources` (не rebase, не force).
- Конфликты решай так, чтобы работало **и моё, и новое**. По каждому конфликту — одна строка: файл, что было у меня,
  что пришло, что оставил. Если совместить нельзя (два разных поведения одного и того же) — остановись и спроси меня.
- Если мои правки добавляют подсказки поверх игры в обход фильтра внимания (прямо в окно `src/hud`), — скажи мне:
  новые подсказки должны идти через `CoachEngine` → фильтр, иначе они будут мешать в драке.
- Если у меня свои горячие клавиши — проверь, что они не совпадают с `Ctrl+Alt+N` (заглушить) и `Ctrl+Alt+F` (фокус).
- Не коммить локальную строку кэша в `.npmrc` (`cache=...` с путём моего диска), если поменял её под себя.
- `package.json` → `version` оставь как в `origin/sources` ({VERSION} или новее), если я не попрошу иначе.

## 4. Проверь
- `npm ci`, затем один раз `node node_modules/electron/install.js`.
- `npm run typecheck`, `npm test`, `npm run test:e2e` — всё должно пройти.
  Ожидаемые пропуски — не ошибка: тесты распознавания на кадрах `tests/fixtures/hud` (с никами, в репозиторий не входят),
  e2e «портативная сборка» (нужен `DOTACOACH_PACKAGED_EXE`), e2e на записи пользователя (нужен `DOTACOACH_USER_VIDEO`),
  тест пути Steam из реестра Windows (идёт только в CI), прогоны на записях матчей владельца. Любой другой пропуск или
  падение — чини и запускай заново.
- Мой `settings.json` обновится сам при первом запуске — **ничего руками не правь** (это проверяет
  `tests/unit/settings-migration.test.ts`, в том числе файл 0.17.0 без разделов `gate` и `focus`).

## 5. Не делай без моего «да»
- Не пушь в `sources` и не меняй `version`. Если я попрошу отправить мои правки — делай отдельный коммит поверх
  свежего `origin/sources`; при push GitHub сам прогонит проверки (`checks`: типы, unit, e2e).
- Не трогай `.github/workflows/*` и `resources/` (база знаний рядом с `app.asar` — через автообновление не доходит).
- Не добавляй зависимости.

## 6. Отчёт (по-русски, коротко)
Какие мои правки нашёл и сохранил (ветка, тег), список конфликтов и решений, результаты проверок с числом тестов,
что осталось решить мне.

## Правила проекта (кратко)
- Комментарии и тексты интерфейса — по-русски. `src/core` не импортирует electron, node:*, fs, path, http.
- Доступ к игре только на чтение: захват окна, Valve GSI (Dota сама присылает данные на 127.0.0.1) и чтение файлов
  настроек. Никакой памяти процесса, DLL, ввода в игру.
- Live-подсказки: по решению владельца включены по умолчанию, в рейтинге — переключатель в «Настройках» (решает игрок).
- Подсказки поверх игры — только через фильтр внимания (`src/core/gate`): 1–3 слова, голос — только для срочных.
- Новые ключи настроек — со значениями по умолчанию; старый `settings.json` должен загружаться без потерь.
- Новый IPC: проверка отправителя в main, `contextBridge` в preload, проверка данных через zod; новый метод API — в
  список `tests/e2e/app.spec.ts`.
- Кадры с никами, записи матчей с чужими данными и файлы установленной программы в репозиторий не класть.
- Выпуск версии (только владелец): поднять `version`, написать `docs/release-notes/v<версия>.md`, запушить в `sources`;
  выпускать, только когда последний прогон `checks` зелёный.
