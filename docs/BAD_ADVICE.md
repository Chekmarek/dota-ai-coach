# «Плохой совет» — отметка в игре и разбор

## В игре

Подсказка не к месту — нажмите **Ctrl+Shift+F8**. Клавиша меняется в «Настройках» → «Подсказки»: щёлкнуть по полю
«Клавиша „плохой совет“» и нажать сочетание. Там же «Выключить».
- Клавиша глобальная (Electron `globalShortcut`): коуч ловит её сам, в игру ничего не вводит и не нажимает. Пока коуч
  запущен, это сочетание не доходит ни до Доты, ни до других программ.
- Принимаются только сочетания с Ctrl или Alt; буква или цифра — минимум с двумя модификаторами; Alt+F4 нельзя. Так
  клавиша не отнимет у Доты способности, метки и группы, а у чата — заглавные буквы.
- Если сочетание заняла другая программа, «История советов» об этом скажет — выберите другое.
- Поверх игры на 2,5 с появляется «Отмечено: плохой совет».
- **Вне матча** (меню, выбор героев, после победы) и при выключенных подсказках клавиша ничего не пишет.

## Что сохраняется

Файл `<папка данных>\bad-advice\<время запуска коуча>\<время отметки>-<матч>.json`:
- подсказки на экране в момент нажатия и все, показанные за 15 с до него (вдруг нужная уже исчезла);
- игровое время, матч, герой, режим;
- снимки состояния матча за последние 15 с (примерно 2 в секунду). Как их видит коуч: свой герой (уровень, HP,
  мана, золото, место, предметы, способности), союзники и враги (герой, жив, место и его давность, HP, «пропал»),
  вражеские полоски на экране, «врагов рядом», стадия игры и позиция.

Снимок собирается **только из перечисленных полей** (`src/core/coach/bad-advice.ts`). Ников, steamid, accountid,
чата и сырых тел GSI в нём нет: это проверяет тест `tests/unit/bad-advice.test.ts`. Хранятся последние 30 запусков
коуча. В «Истории советов» у матча появляется блок «Отмечено как плохой совет» с временем и подсказками, а в списке
— фильтр «только с отметками».

## Разбор в Claude Code

```
npm run bad-advice                      # последняя сессия → .tmp\bad-advice-<сессия>.md
npm run bad-advice -- --all             # все сессии
npm run bad-advice -- --session <папка> --out отметки.md
```

Получается один Markdown. По каждой отметке: что было на экране, кратко последнее состояние (я, враги, «врагов
рядом», полоски) и полный JSON под спойлером. Этот файл можно сразу дать Claude Code: «разбери плохие советы из
.tmp\bad-advice-….md».
