Что нового в 0.7.0:
- Значок «Коуч» появляется с анимацией: рамка разворачивается, руны делают быстрый оборот, вылетают искры.
- Око моргает примерно каждые 7–15 с, иногда дважды. Раз в 45–90 с случается одна из вспышек: руны загораются по очереди, из глаза поднимаются угольки или по рамке проходит золотой блик.
- При потере картинки значок встряхивается, камень вспыхивает красным, око полуприкрывается и мерцает. При восстановлении расходится зелёное кольцо.
- Когда коуч выключают или Дота уходит, значок сворачивается.
