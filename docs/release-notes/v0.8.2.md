Что нового в 0.8.2:
- Данные из игры (GSI): Dota сама присылает коучу точные время, золото, уровень, здоровье, ману, способности и предметы вашего героя — быстрее и точнее, чем по картинке.
- Как подключить: «Живая игра» → «Подключить» → в Steam: Dota 2 → Свойства → Параметры запуска → добавить `-gamestateintegration` → перезапустить Dota. В меню Dota данных не шлёт — статус «ждём Dota» там нормален; данные пойдут, когда загрузится матч или Hero Demo.
- Если путь к Steam с русскими буквами (например, D:\Игры\Steam), коуч теперь сам находит папку Dota.
- Записи сессий занимают не больше 500 МБ: самые старые дни удаляются сами.
- Данные из игры принимаются сразу после запуска коуча, и смена порта в настройках больше не оставляет «лишний» приёмник.
