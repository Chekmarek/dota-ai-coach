Что нового в 0.11.0 — ИИ-помощник:
- Новая страница «ИИ-помощник» и поле «Спросить» на «Живой игре», «Разборе записи», «Состоянии матча» и «Базе знаний». Спросите по-русски: «сколько стоит BKB?», «когда руна силы?», «кто из врагов мёртв?», «сколько золота было в записи?» — коуч отвечает 1–5 предложениями только по своим данным: текущий матч, база знаний патча 7.41f, разбор записи. Чего нет в данных — честно «не знаю».
- ИИ ничего не считает и не смотрит игру сам — только объясняет то, что посчитал коуч. Каждое число в ответе сверяется с данными; если числа нет в данных, ответ помечается «⚠ не проверено», а число подсвечивается. Под ответом — «какие данные использованы» и кнопки «Полезно» / «Мимо» (сохраняются только на вашем ПК).
- «Разбор матча» на странице «ИИ-помощник» (по записанным данным игры) и в конце «Разбора записи»: смерти со временем, уровень и золото по минутам, предметы со временем, простои. Без ИИ показывается список фактов, с ИИ — короткий разбор до 10 строк.
- По умолчанию ИИ выключен — коуч работает как раньше.

Как включить локальный ИИ (бесплатно, без интернета, видеокарта не нужна):
- «ИИ-помощник» → «Кто отвечает» → «Локальная модель на этом ПК» → «Скачать локальный ИИ». Скачивается один раз: Qwen3 1.7B — 1,03 ГБ (по умолчанию) или Qwen3 4B — 2,33 ГБ (умнее, медленнее), плюс программа llama.cpp — 19 МБ. Файлы проверяются, обрыв связи — докачка, «Удалить» стирает всё.
- На проверочном ПК: 1.7B отвечает через ~3 с, ~27 токенов (кусочков слов) в секунду, занимает ~1,5 ГБ памяти; 4B — через ~8 с, ~13 токенов/с, ~3 ГБ. На слабом ПК медленнее.
- Модель запускается только когда вы спрашиваете и выключается через 5 минут без вопросов. Во время матча отвечает короче, чтобы меньше нагружать процессор.

Как подключить бесплатный облачный ИИ (по желанию):
- Возьмите бесплатный ключ у любого сервиса с OpenAI-совместимым API. «ИИ-помощник» → «Облако» → адрес API (оканчивается на /v1), имя модели, ключ → «Сохранить», затем включите согласие на отправку. Без согласия в облако ничего не уходит.
- В облако уходят только вопрос и игровые факты коуча — без ников, steamid и ключей. Ключ шифруется Windows и хранится только на вашем ПК.
- GigaChat пока недоступен: ему нужен отдельный сертификат, который коуч не устанавливает.

Дальше: подсказки во время матча на основе ИИ — в следующих обновлениях.

Ограничения: проверка чисел не замечает ошибку в словах (например, «ближний» вместо «дальний бой») — сверяйтесь с «какие данные использованы». Подробности — в docs/LIMITATIONS.md, что уходит в облако — в docs/POLICY.md.
