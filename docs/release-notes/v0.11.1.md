Исправления 0.11.1 — по проверке ИИ-помощника на настоящем коуче:
- ИИ больше не выдумывает: если у коуча нет данных по вопросу (например, «кто выиграл The International?»), сразу отвечает «не знаю». Имена латиницей (герои, предметы, команды), которых нет в данных коуча, теперь тоже помечаются «⚠ не проверено», как и числа.
- Во время матча ответ короче — одно-два предложения — и не обрывается на полуслове.
- Локальная модель читает данные матча примерно в 1,5 раза быстрее: Qwen3 1.7B отвечает о матче через 6–7 с вместо 8–11 с. Память — около 1,7–1,9 ГБ.
- Обновление: если Windows спрашивает разрешение («Контроль учётных записей») и окно спряталось за другими, коуч больше не пишет «Установка отменена» через 2 минуты — он ждёт вашего «Да», подсказывает, где окно, и перезапускается сам.

Проверено: имитация игры (4 потока, 144 к/с) не теряет кадров, пока ИИ отвечает. FPS в самой Доте ещё не измерен — расскажите, если заметите просадки.
