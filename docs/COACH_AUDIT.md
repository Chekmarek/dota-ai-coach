# Аудит подсказок коуча (этап 1, 2026-10-18, версия 0.13.7)

Источник частот — история 5 матчей Турбо 2026-10-18 (916 подсказок, ~180 за матч, ~7 в минуту).

## Откуда коуч берёт данные

- **Dota GSI** (свой герой): часы, здоровье/мана, уровень, золото, предметы с перезарядкой, способности, выкуп,
  здания своей команды, события (Рошан, Аегис). Позиции врагов GSI игрока не даёт.
- **Экран** (живой захват): мини-карта (кто где, кто пропал), верхняя панель (живы ли враги), полоски здоровья над
  героями (здоровье и уровень врагов рядом, без имени героя).
- **Статистика OpenDota** (файлы в `src/data`, обновляются скриптом): сборки и навыки профи, добивания профи к 10:00,
  медианы GPM/XPM, матчапы, у Турбо — отдельный файл без норм.
- **База механик** (Liquipedia, патч-ноуты): руны, Рошан, стак, лотосы, нейтральные предметы, Турбо.
- **Локальная модель** (llama-server, сейчас qwen3-1.7b): выбирает «что делать и куда» из списка правил, пересказывает
  шаблонные подсказки, объясняет ошибки и разборы. Ответы проверяются по фактам (числа), но не по смыслу.

## Две ошибки из задачи

**«Фармите лес на 1-й минуте».** Совет «что делать» (`prob.ts: actionChoice`) не знает ни стадии, ни роли:
у фарма постоянный перевес (+0.6) и ещё +0.4 «ранняя игра» до 10:00, поэтому до 10-й минуты почти всегда выигрывает
«фармить». Куда фармить (`ai.ts: adviceOptions`) — всегда свой лес, а линия — только если герой прямо сейчас стоит
на линии (в первые минуты он часто в реке или идёт по лесу). Модели остаётся выбрать «лес Сил Тьмы». Совет приходит
сразу с 0:00 (повод «first») и после каждого возрождения. Так было в матче 9051402480 в 2:38 («Фармить: лес Сил
Тьмы» оффлейнеру) и во всех трёх матчах.

**«Съешьте Tango» как причина смерти в лейте.** Разбор смерти считал любой предмет, который можно нажать, — включая
Tango, Healing Salve, Clarity (матчи 9051402480 5:11/8:10, 9051512826 9:58). В 0.13.7 расходники из разбора убраны
совсем. Но остались: правило «Мало здоровья — съешьте Tango / выпейте Healing Salve» работает до 20:00 (в Турбо 20:00 —
уже лейт), и «главная ошибка матча» строится из тех же «неиспользованных ресурсов». Общая причина — у коуча нет
понятия стадии игры: пороги — минуты обычной игры, в Турбо они то масштабируются, то нет.

## Общие проблемы

1. **Нет стадии игры** — пороги «до 10/20/25/35 мин» из обычной игры, в Турбо применяются непоследовательно.
2. **Нет роли (позиции 1–5)**: есть только `laneRole` (линия с 1:00 до 8:00, позиции 1–4, без 5) и «кор/саппорт» по
   статистике героя. Советы одни для керри и для пятёрки.
3. **Слишком много подсказок**: ~7 в минуту; три правила отвечают на один вопрос «что делать» (вступать, действие,
   совет ИИ), два правила стака дублируют друг друга.
4. **Текст маленькой модели** проверяется только по числам: бессмыслица проходит (в 0.13.7 убрана из совета, но
   пересказ шаблонов моделью ещё включён).
