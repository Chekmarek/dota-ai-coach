# Источники игровых данных

Правила:
- Каждая запись хранит источник, дату получения и патч (`resources/data/kb/<патч>/meta.json`).
- Импортированные данные помечаются `imported-unverified`, пока не сверены с официальными патч-ноутами.
- Механика карты (`mechanics.json`): `verified` — только если значение прямо написано в патч-ноутах Valve текущей серии
  (импортёр ищет строку `valveNote` в 7.41 … 7.41f) или пришло из Valve datafeed; иначе `imported-unverified`;
  нет источника — `missing` и `null`. По памяти ничего не заполняется.
- База едет внутри `app.asar` (приходит с автообновлением) и копией в `resources\data` рядом с программой; берётся более новая.
- Точные расчёты (exact) не используют непроверенные данные.
- Во время работы приложение **ничего не скачивает** — база собирается скриптом `npm run kb:import` и едет внутри сборки.
