# Источники игровых данных

Правила:
- Каждая запись хранит источник, дату получения и патч (`resources/data/kb/<патч>/meta.json`).
- Импортированные данные помечаются `imported-unverified`, пока не сверены с официальными патч-ноутами.
- Точные расчёты (exact) не используют непроверенные данные.
- Во время работы приложение **ничего не скачивает** — база собирается скриптом `npm run kb:import` и едет внутри сборки.

| Набор | Источник | Лицензия | Получено | Патч | Статус |
|---|---|---|---|---|---|
| Патч, герои, характеристики, способности, таланты, описания на русском | Valve datafeed — `https://www.dota2.com/datafeed/` (patchnoteslist, herolist, herodata) | публичные данные Valve | 2026-10-11 | 7.41f (2026-09-15) | imported-unverified |
| Предметы (цена, рецепты, атрибуты), роли героев | OpenDota dotaconstants — `https://github.com/odota/dotaconstants` (ветка master, коммит от 2026-10-10) | MIT | 2026-10-11 | 7.41f | imported-unverified |
| Шаблоны символов HUD | Кадры записей пользователя (`tests/fixtures/hud`) | собственные данные пользователя, не публикуются | 2026-10-11 | 7.41e | ручная разметка |

Самопроверка: цена собранного предмета сравнивается с суммой частей и рецепта — расхождения видны на экране «База знаний».
