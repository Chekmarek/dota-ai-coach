# Правила для Claude Code в этом проекте

## Язык
- **Всегда отвечай владельцу по-русски**: отчёты, вопросы, объяснения, итоговые сообщения — даже если промпт написан
  по-английски. Английский — только для кода, команд, путей и цитат из логов.
- Комментарии в коде, тексты интерфейса, сообщения коммитов и документация — тоже по-русски.

## Работа с репозиторием
- Работаем только в ветке `sources` (в начале — `git pull`). В `main` не пушить, теги и релизы вручную не создавать,
  `.github/workflows/*` не менять.
- Релиз выходит сам, когда в `sources` поднята `version` в package.json. Поднимать версию — только когда последний
  прогон `checks` (типы, unit-тесты, e2e на Windows) зелёный.
- Друг обновляется только кнопкой «Обновления» → «Установить» (заменяется лишь `app.asar`): ему не должно быть
  нужно ничего скачивать или править руками.
- `src/core` не импортирует electron, node:*, fs, path, http. Новые зависимости — только после вопроса владельцу.
